# 🌳 모여봐요 공부의 숲 

> 한국사능력검정시험(한능검) 대비 스터디 & 문제풀이 플랫폼

시대별 공부 복장을 입은 캐릭터와 함께 스터디룸에서 공부하고, 문제은행으로 실력을 다지고, 한능검 1급 합격 시 **장원급제 명예의 전당**에 이름을 올리는 학습 플랫폼입니다.

---

## 📌 주요 기능

### 👤 회원·캐릭터
- 회원가입 / 로그인·로그아웃
- 닉네임 설정
- 시대별 캐릭터 선택·변경 (선사시대 · 삼국시대(화랑) · 유생 · 근현대(개화기) × 성별 2 = 총 8종)
- 회원 탈퇴 (합격 인증 시에만 가능)

### 🪑 스터디 공간
- 공용 스터디룸 입장 및 빈 좌석 선택
- 착석·퇴실 / 캐릭터·닉네임 표시
- 실시간 공부 시간 표시
- 사용자 공부 정보 확인 (공부 과목, 오늘의 목표, 목표 시간, 현재 공부 시간, 투두 완료율)

### 📖 한능검 문제은행
- 시대별 / 랜덤 문제 풀이
- 객관식 자동 채점 및 정답·해설 확인
- 풀이 기록 저장
- 오답노트 (오답 자동 저장 · 다시 풀기)
- AI 생성 모의고사 문제에 👍/👎 평가 → 인기 문제 모아 풀기

### 🤖 AI 질의응답
- 문제 관련 질문 / 한국사 개념 질문
- 추가 해설 제공
- 대화 기록 저장

### ⏱️ 나의 공부
- 공부 과목 설정 / 오늘의 목표 · 목표 시간 설정
- 타이머 (시작 · 일시정지 · 종료·기록 저장)
- 투두리스트 (등록 · 수정 · 완료 · 삭제)

### 📊 학습 통계
- 오늘·누적 공부 시간
- 총 문제 풀이 수 / 전체·시대별 정답률
- 취약 시대 표시

### 🏆 장원급제
- 한능검 1급 합격 인증 신청
- 관리자 승인·반려
- 합격자 명예의 전당 (닉네임 · 합격 회차 · 합격 한마디)

### 🛠️ 관리자
- 회원 조회 / 문제 등록·수정·삭제
- 시대·주제·난이도 관리
- 합격 인증 승인·반려 / 스터디 좌석 관리

## 📝 커밋 컨벤션

### 커밋 메시지 형식

```
<type>: <subject>

<body>
```

### Type

| Type | 설명 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 (README 등) |
| `style` | 코드 포맷팅, 세미콜론 누락 등 (기능 변경 없음) |
| `refactor` | 코드 리팩토링 (기능 변경 없음) |
| `test` | 테스트 코드 추가·수정 |
| `chore` | 빌드·설정·패키지 등 기타 작업 |
| `design` | UI/CSS 등 디자인 변경 |
| `comment` | 주석 추가·변경 |
| `rename` | 파일·폴더명 변경 |
| `remove` | 파일 삭제 |

### 작성 규칙
- 제목은 50자 이내, 마침표 없이 작성
- 제목은 명령문·현재형으로 작성 (예: `추가한다` X → `추가` O)
- 본문은 "무엇을, 왜"에 초점 (어떻게 X)
- 이슈 번호가 있으면 하단에 참조 (`#123`)

### 예시

```
feat: 스터디룸 좌석 선택 기능 추가

빈 좌석 클릭 시 착석 처리 및 캐릭터 표시 구현

#12
```

```
fix: 타이머 일시정지 후 시간 중복 저장 오류 수정
```
